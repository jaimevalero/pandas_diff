============
Installation
============

Stable release
--------------

Install pandas_diff with pip:

.. code-block:: console

    $ pip install pandas_diff

With Parquet support:

.. code-block:: console

    $ pip install "pandas_diff[parquet]"

From sources
------------

.. code-block:: console

    $ git clone https://github.com/jaimevalero/pandas_diff
    $ cd pandas_diff
    $ pip install -e ".[dev]"
